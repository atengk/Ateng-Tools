# 0014. 首页居中聚合门户重构与信息视觉韵律优化

## 状态
已提议 / 待确认 (Proposed)

## 背景与上下文
在 Ateng-Tools 现有首页（参见 issue 讨论与运行截图）中，随着收录工具扩充至 114+ 款，用户在首页工具发现与日常使用中面临以下体验痛点：
1. **首屏利用率低与垂直视线摆动**：Hero 横幅占高过大且右侧大片空白，独立的 760px 居中搜索框与左对齐的 Hero、分类标签产生明显的“左-中-左”视线摆动；
2. **收藏区少态下空间失衡**：常用收藏区简单复用 4 列网格，当用户仅有 1~2 个收藏工具时，右侧呈现 75% 的视觉空洞；
3. **分类筛选指示冗余**：右侧常驻的“当前分类：全部工具”文字与左侧已高亮处于激活态的药丸产生重复提示；
4. **卡片视觉层次平淡**：裸露的 36px 纯图标与普通文本在整屏铺排时缺乏现代 SaaS 控制台的几何韵律与操作引导。

## 架构决策
经过两轮设计树（Design Tree）推演与交互式原型验证，决定对 Ateng-Tools 首页进行系统级排版与视觉重构：

1. **一体化居中聚合门户 (Portal Hero Section)**：
   - 将离线安全徽章、主副标语、4 大核心特性指标胶囊（114+ 款精选工具、100% 本地离线执行、8 大垂直领域、0 外部网络追踪）与 `HomepageToolSearchFilter` 深度融合为一个居中聚合单元；
   - 彻底解决横幅左右留白失衡与搜索框孤立悬浮问题。

2. **常用收藏灵动货架 (Favorites Quick Shelf)**：
   - 常用收藏脱离 4 列大卡片网格，重构为自适应横向弹性微磁贴卡片（包含微底色图标、精炼标题、所属分类、一键移出与拖拽手柄）；
   - **空态静默隐藏**：当收藏数为 0 时，收藏区完全不渲染，首屏视野彻底让渡给全量工具。

3. **分段分类控制栏 (Categorized Segmented Control)**：
   - 统一引入 `@vicons/tabler` 原生矢量领域分类图标（`Apps`、`Terminal2`、`ArrowsExchange`、`ShieldLock`、`World`、`FileText`、`FileTypePdf`、`Photo`、`Calculator`）；
   - 移除右侧冗余的“当前分类”指示，释放水平呼吸感。

4. **增强工具卡片 (Enhanced Tool Card) 质感升级**：
   - 引入 40×40px 微底色圆角图标容器（`Micro-Surfaced Icon Container`），统一卡片视觉焦点；
   - 优化字阶与行高（15px 加粗标题，12px 呼吸感描述）；
   - 增加卡片底部辅助操作条（左侧高频特性标签，右侧浅色“打开工具 →”悬浮指引）；
   - 严格遵循 `Surface Elevation Hierarchy` 规范，Hover 时提供轻微微浮雕与柔和品牌蓝光晕。

5. **黄金视口约束边界 (Viewport Rhythm Boundary)**：
   - 首页容器强制添加 `max-w-7xl`（约 1360px）并居中，保障 1080p、2K 与超宽带鱼屏下视距收拢与卡片对齐。

## 后果与影响
- **正面影响**：首屏可直接展现 2~3 排工具卡片，工具发现效率提升约 40%；视觉动线流畅垂直收敛；深浅主题在设计令牌下完全统一。
- **代价与权衡**：需要对 `Home.page.vue` 与 `ToolCard.vue` 模板与样式进行系统化重组，并补充对应的单元测试覆盖。
