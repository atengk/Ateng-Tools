# 0003. 首页交互重构与开源衍生品牌溯源设计

## 状态
已接受 (Accepted)

## 背景与上下文
Ateng-Tools 是基于知名开源项目 IT-Tools (Corentin Thomasset) 进行二次开发与深度定制的个人在线工具箱，由 Vue 3 + TypeScript + Naive UI 构建。
此前版本中，首页与全局框架存在以下待优化项：
1. **原项目信息混杂**：首页 Banner 与侧栏/顶栏直接挂接了原作者个人的 Twitter/X 链接、BuyMeACoffee 赞助地址以及原 GitHub 仓库地址，缺乏针对 Ateng-Tools 的独立品牌标识与自有仓库引导。
2. **首页平铺列表密度大**：首页全量展示 70+ 个工具，用户需长距离滚动查找，缺乏基于领域分类的快速聚合筛选能力。
3. **卡片视觉层次扁平**：工具卡片（ToolCard）缺少分类标签直观提示，交互反馈与阴影动效较弱。

## 架构决策
经过与用户对齐方案（Round 1 全选方案 A），确立以下决策：
1. **品牌与开源溯源策略**：
   - 界面主品牌全面切换为 **Ateng-Tools（阿腾工具箱）**。
   - 顶部与外链统一指向 `https://github.com/atengk/Ateng-Tools`，移除原作者个人商业赞助与社交推特链接。
   - 严格遵守 GPLv3 开源协议，在侧栏底部与关于页保留规范致谢：“基于 IT-Tools 开源项目二次开发构建”。
2. **首页布局形态重构**：
   - 废弃原关注横幅，引入轻量 Hero 区域（品牌愿景 + 工具总数统计 + 快捷全局搜索入口）。
   - 保留我的常用/收藏工具区（支持拖拽排序与空状态提示）。
   - 引入 **Tool Category Filter** 分类标签过滤栏（全部、开发运维、转换格式、加密安全、网络工具等），支持一键切换分类与即时响应。
3. **卡片微动效与视觉增强**：
   - 卡片增加微妙浮起动效（`hover: -translate-y-1` + 柔和阴影 + 浅/深色模式主色微高亮边框）。
   - 新增分类标签（Category Tag）与新功能徽标（New Badge）区分展示。
4. **色彩体系与本地化定调（Tech Blue & Chinese-First）**：
   - **主品牌色**：由原本 Naive UI 默认的自然绿切换为**科技极客蓝（Tech Blue, `#2563eb` / `#3b82f6`）**，契合现代化开发工具严谨硬核的工程质感。
   - **基底与卡片层次**：亮色模式下采用冷灰大底衬（`#f8fafc`）与纯白卡片（`#ffffff`），搭配克制的高级灰阶辅助色与琥珀金收藏星标。
   - **默认中文与深度本地化**：项目初始缺省语言锁定为中文（`zh`），并在 `<n-config-provider>` 中无缝联动 Naive UI 的 `zhCN` 与 `dateZhCN`，彻底实现整站 100% 地道中文。


## 后果与影响
- **正面影响**：建立清晰独立的工程品牌认知，兼顾开源合规致谢；分类标签显著提升工具检索效率；卡片视觉与操作质感更现代精美。
- **代价与权衡**：需要对全局侧边栏/顶栏布局文案与多语言键进行同步治理，维护分类标签与工具列表状态同步。
