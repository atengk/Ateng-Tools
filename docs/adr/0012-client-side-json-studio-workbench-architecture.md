# 0012. 纯客户端一站式 JSON 综合工作台架构决策 (JSON Studio)

## 状态
已接受 (Accepted)

## 背景与上下文
在日常前后端联调、接口测试、日志排查与数据清洗中，JSON 是开发者使用频次最高的数据载荷格式。然而，Ateng-Tools 现有的 JSON 工具链呈现出“功能单一、能力离散”的痛点：
1. 存量的 `json-viewer`（路由为 `/json-prettify`）仅依赖基础 `json5` 实现了键名排序和简单缩进，缺乏深度交互树、节点折叠、节点路径提取等关键能力；
2. 存量的 `json-minify` 仅做单行压缩，工具形态碎片化；
3. 面对来自生产日志、网关错误或 Python 后端的非标 JSON（缺失双引号、单引号包裹、尾随逗号、包含 JS 注释或 Python 字面量 `None`/`True`/`False`），现有工具直接解析抛错，无法进行容错清洗与智能修复；
4. 缺乏从日志嵌套提取中的转义反转义（String Escape/Unescape）、深度 JSONPath 条件检索、前后端键名风格批量转换（驼峰/下划线）及点号路径扁平化（Flatten/Unflatten）等高级生产力能力。

基于 [ADR-0001](0001-client-side-dev-tools-architecture.md) 确立的纯客户端离线安全架构基线，用户的敏感业务数据、Token、内部日志绝不离开本地。因此，必须在浏览器端构建高内聚、交互流畅、具备性能防御体系的一站式 **JSON 工作台 (JSON Studio)**。

## 架构决策

经过多轮深度问辩（Grilling Session）与领域建模，确立以下核心架构与技术决策：

### 1. 产品形态与全站八大领域分类归属
- **工作台形态 (JSON Studio)**：借鉴站内 `Image Studio`（[ADR-0004](0004-image-studio-client-side-pipeline-architecture.md)）与 `PDF Studio`（[ADR-0005](0005-client-side-pdf-toolkit-and-studio-architecture.md)）的成熟范式，将 JSON 的高亮编辑、树状探索、JSONPath 提取、非标修复、转义还原、命名转换与度量统计高度集成于 `json-studio` 工作台，杜绝多页面跳转复制的割裂感。
- **分类落位 `dev` (开发运维)**：依据 [ADR-0006](0006-canonical-tool-taxonomy-and-category-consolidation.md)，JSON 工作台核心服务于接口联调、数据校验、微服务调试与清洗，与 `http-client`、`websocket-and-sse-client` 和 `curl-converter` 具备强烈的协同链路，统一归入 `dev` 分类。

### 2. 双栏响应式抗溢出工作台布局
- **分屏交互拓扑**：采用左右双栏弹性布局（大屏左右分屏，移动端小屏断点自适应纵向折叠）：
  - **左栏（代码编辑工作区）**：引入项目已有的 `monaco-editor` 引擎，提供 VSCode 级代码高亮、行号、代码块折叠、快捷键、文件拖拽导入与输入尺寸统计；
  - **右栏（多维透视与功能视窗）**：采用轻量 Tab 切换器，提供 5 大专属视图：`🌲 交互式树形图`、`🔍 JSONPath 提取`、`🛠️ 清洗修复与转义`、`🔄 结构与命名转换`、`📊 度量大纲`；
  - **顶栏（全局快速操作流）**：常驻高频操作按钮组（格式化、单行压缩、智能修复、转义/去转义、清空、示例数据载入、复制结果、下载 `.json` 文件）。
- **布局防溢出**：全部分栏与代码展示容器显式应用 `min-w-0` 与自适应换行，彻底防范超长单行 JSON 穿透卡片右侧边界。

### 3. 交互式树形透视引擎 (Interactive Tree Explorer)
- **多层级折叠控制**：提供顶栏快捷分级开关（`全部展开`、`全部折叠`、`展开至第 1/2/3 层`），轻松应对十数层深度的大型嵌套对象。
- **绝对 JSONPath 快速捕获**：在每个节点旁提供操作锚点，一键复制当前节点的**绝对 JSONPath 路径**（如 `$.data.users[0].profile.email`），极大提效后端接口对接。
- **节点值即时提取**：支持一键复制节点原始值（基本类型提取纯文本值，复杂对象提取局部格式化代码）。
- **树内关键字检索**：支持树内实时文本过滤，命中节点高亮着色并自动级联展开其父节点链路。

### 4. JSONPath 检索引擎与双轨呈现 (JSONPath Query Engine)
- **纯客户端查询执行**：支持标准 JSONPath 语法（根选择器 `$`、通配符 `*`、切片 `[start:end]`、深度递归 `..`、属性过滤表达式 `[?(@.price > 50)]`）。
- **双轨结果反馈**：
  1. **独立提取视图**：以格式化只读代码区呈现提取出的结果集合，展示命中计数徽章（如 `匹配到 12 个节点`），支持一键独立复制与导出；
  2. **树形联动透视**：在树形图中同步高亮标记所有命中节点，直观呈现其在原数据树中的上下文层级。

### 5. 非标语法容错与智能修复管线 (JSON Smart Repair)
- **规则覆盖范围**：
  1. 属性键名缺失双引号纠正（`{ name: "Tom" }` ➔ `{"name": "Tom"}`）；
  2. 单引号键或值纠正为严格双引号（`{'status': 'ok'}` ➔ `{"status": "ok"}`）；
  3. 尾随冗余逗号清除（`[1, 2, 3, ]` ➔ `[1, 2, 3]`）；
  4. JavaScript 单行与多行注释剥离（`//`、`/* */`）；
  5. Python 风格字面量纠偏（`None` ➔ `null`，`True` ➔ `true`，`False` ➔ `false`）；
  6. 未转义换行符与控制字符合规化纠偏。
- **防破坏性安全预览流**：修复操作默认不在左侧直接盲目覆盖，而是在右侧“修复结果对比”视窗中呈现修复前后 Diff，并提供“一键应用回编辑器”与“单独复制”按钮，确保用户对代码变更具备完全把控权。

### 6. 字符串转义与反转义 (String Escape / Unescape)
- **双向无损转换**：
  - **Unescape（反转义还原）**：针对开发者从日志、网关或代码字符串中复制出的转义 JSON（如 `"{\"code\":200,\"msg\":\"ok\"}"`），剥离外层引号并还原内部 `\"` 为真实双引号，解析还原为标准 JSON 对象；
  - **Escape（转义包裹）**：将当前 JSON 压缩并转义为可直接嵌入 Java/JS/Python 代码字符串字面量的紧凑安全转义串。

### 7. 结构扁平化与键名风格转换 (Key Case Transformer & Flatten)
- **全深度递归键名转换**：支持在 `camelCase`（小驼峰）、`snake_case`（下划线）、`kebab-case`（中划线）、`PascalCase`（大驼峰）之间双向任意无损递归转换，解决跨语言开发中命名规范不一致的痛点。
- **点号路径可逆扁平化**：提供对象树与 Dot-notation 扁平键值对之间的双向无损互转（`a.b[0].c` ↔ 嵌套对象），支持数组以索引（`0`）或方括号（`[0]`）展开。

### 8. 客户端性能防御门禁 (Performance & Memory Guard)
针对超大型 JSON 数据 dump 设置三级性能防御门禁：
1. `< 2MB`：全量启用 Monaco 语法诊断、完整双向响应式更新、全功能树形透视；
2. `2MB ~ 10MB`：自动激活大文本防御模式，Monaco 关闭部分深度标记，树形图默认仅展开第一层并采用按需懒加载，防止 DOM 爆炸；
3. `> 10MB`：弹出大文件预警提示，建议优先使用流式压缩/格式化或下载，避免主线程渲染卡顿。

### 9. 存量旧工具的平滑兼容策略 (Legacy Compatibility)
- 保留现有的 `json-viewer`（路由 `/json-prettify`）和 `json-minify`，保证外链与书签向后兼容；
- 在旧工具顶部挂载显著的平滑升级引导横幅（“✨ 体验全新一代 JSON 综合工作台”）；
- 在侧边栏与首页将新的 `json-studio` 置于首要推荐位置。

## 后果与影响

- **正面影响**：
  - 一站式解决 JSON 格式化、压缩、排查、树状浏览、提取、修复、转义等全流程诉求，彻底终结“功能单一”的痛点；
  - 100% 纯客户端离线计算，严格捍卫用户数据与内部日志的隐私安全；
  - Monaco Editor 带来 IDE 级流畅编辑体验与代码折叠能力；
  - 完善的性能分级防御，杜绝巨型数据崩溃。
- **代价与权衡**：
  - 纯客户端计算受宿主浏览器可用内存与 CPU 单线程限制，针对数百兆超大离线日志需引导用户流式处理；
  - 非标 JSON 智能修复基于状态机与规则替换，极端恶意混淆文本可能存在边界无法识别，需依靠安全预览流保障确认权。
