# 0005. 纯客户端 PDF 工具体系与 PDF Studio 工作台架构设计

## 状态
已接受 (Accepted)

## 背景与上下文
随着个人开发者在线工具箱的高频使用，用户在日常开发、办公与合同流转中对 PDF 文件处理的诉求极其迫切，包括多文档合并、合同与证件页面拆分/抽取、图片与 PDF 格式互转、页面旋转重排、图文水印印章以及敏感文档加解密。
目前市场上主流的在线 PDF 工具（如 Smallpdf、iLovePDF 等）均采用后端上传处理机制，存在严重的代码文档、业务契约或个人身份凭证泄漏风险；同时，若在前端引入大型 WebAssembly 方案（如 MuPDF 或 Ghostscript WASM），会导致打包产物体积激增（通常数十兆至上百兆），严重拖慢首屏性能与 GitHub Pages 静态分发效率。
此外，当前工具箱现有分类中已收录有 `pdf-signature-checker`（PDF 签名校验工具），此前暂时归入 `Crypto`（加密）分类，缺乏统一的文档处理领域心智。

## 架构决策
我们决定在 Ateng-Tools 中正式引入第一级顶层大分类 **`PDF`（PDF 工具）**，并确立基于纯客户端双引擎协同与虚拟页面列表（Virtual Page Deck）的文档处理架构：

1. **复合产品矩阵形态**：
   - 确立新增顶层一级大分类 `PDF`（PDF 工具），由以下 6 款工具矩阵构成：
     1. `pdf-studio`（PDF 工坊）：旗舰可视化页面编排工作台（合并/拆分/拖拽重排/旋转/删页/水印/实时预览）；
     2. `pdf-to-image`（PDF 转图片）：单页/多页高清位图渲染导出，支持单图直下与批量 ZIP 打包；
     3. `image-to-pdf`（图片转 PDF）：多图拖拽排序与纸张规范（A4/A3/自适应）合成文档；
     4. `pdf-encrypt-decrypt`（PDF 加密与解密）：口令权限保护与已知密码解密剥离；
     5. `pdf-text-extractor`（PDF 文本与元数据提取器）：纯文本抽取与文档详细元属性透视；
     6. `pdf-signature-checker`（PDF 签名校验）：从原 `Crypto` 分类无损平移汇聚。

2. **纯客户端双引擎协同与中文字印方案**：
   - **结构与字节层 (`pdf-lib`)**：以轻量级 (~300KB) 纯 JavaScript 二进制流方式处理文档的底层解析、页面增删、树状旋转、加密权限与无损 Stamp 嵌入；
   - **光栅化渲染层 (`pdfjs-dist`)**：通过 Mozilla PDF.js 引擎离屏渲染指定页面至 Canvas，专门负责页面微缩缩略图展示以及 PDF 导出高清晰位图；
   - **免外部字体水印方案 (Transparent Stamp Rasterizer)**：利用浏览器原生 Canvas 2D 离屏排版将任意字符（中文、生僻字、Emoji）栅格化为透明 PNG，再通过 `pdfDoc.embedPng()` 印入目标页，避免额外下载数十兆外部字体包，保障 100% 离线与跨平台一致视觉。

3. **虚拟页面列表 (Virtual Page Deck)**：
   - 在工作台状态机中，将加载的一个或多个 PDF 文档解析为离散的虚拟页面元数据数组 `{ sourceDocId, originalPageIndex, rotation, isDeleted }`；
   - 所有的排序、旋转、删除操作均为 O(1) 的声明式状态变更；仅在用户点击“导出/下载”时，才根据 Virtual Page Deck 调度 `pdf-lib` 执行一次性精确拷贝与序列化输出，彻底杜绝多次中间编辑导致的性能开销。

4. **视口感知与按需光栅化 (Deferred Rasterizer)**：
   - 对于包含上百页的大型文档，缩略图网格采用 IntersectionObserver 视口按需延迟渲染，限制缩略图渲染宽度（240px），避免全量并发渲染 Canvas 撑爆浏览器内存或锁死 UI 线程；
   - 对超大文件（> 100MB 或 > 200 页）设置轻量容量阈值警示。

5. **内存流式压缩交付 (In-Memory Zip Archiver)**：
   - 多页位图转换与页面批量切片导出统一在浏览器内存中流式归档为 `.zip` 压缩包，避免多重弹窗被浏览器拦截。

## 后果与影响
- **正面影响**：
  - 100% 保护用户核心机密文件与隐私，所有字节流均在浏览器本地内存处理并即时释放，零服务端开销；
  - 极小构建产物体积，依托 `pdf-lib` + `pdfjs-dist` 与离屏印章方案，完全无大型字体与 WASM 膨胀；
  - 统一了系统内的 PDF 领域边界，形成清晰的分类导航心智。
- **代价与权衡**：
  - 超大文档（如 > 500MB 或数千页）受浏览器堆内存（Heap Limit）限制，需在前置设置友好的容量阈值预警。
