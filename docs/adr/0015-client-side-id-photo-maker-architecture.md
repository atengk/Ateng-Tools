# 0015. 纯客户端证件照工坊架构决策 (ID Photo Maker)

## 状态
已接受 (Accepted)

## 背景与上下文
现代开发者与普通用户在高频场景中（如各类国家资格考试报名、社保卡申请、公务员考试、求职简历与护照签证办理）经常面临制作标准证件照的刚性诉求。官方平台通常对照片提出严苛的硬性规范：
1. **精确规格与分辨率**：毫米级物理尺寸与 300 DPI 高清分辨率要求；
2. **合规构图**：头顶距上边框高度、眼平线水平度及面部占比标准；
3. **底色规范**：红底、蓝底、白底或灰底；
4. **文件大小红线**：如“文件大小必须在 20KB ~ 50KB 之间”或“不超过 100KB”；
5. **冲印排版需求**：将多张证件照拼版在 5 寸或 6 寸相纸上，以便去线下打印店经济冲印。

然而市面现存工具大多需要将人脸肖像照片上传至远程云端服务器处理，存在严重的面部生物信息泄漏与数据滥用风险；此外部分端侧 AI 模型方案体积高达数十兆，会导致全站构建产物急剧膨胀，拖累 GitHub Pages 加载性能。

## 架构决策

### 1. 纯客户端离线安全架构 (Zero-Upload Safe by Default)
严格秉承 [ADR-0001](0001-client-side-dev-tools-architecture.md)，所有像素运算、色彩分割、构图对齐、排版拼版与二进制压缩 100% 在浏览器端 Canvas 2D / OffscreenCanvas 内存中执行，绝对不引入任何后端 API 或第三方外网服务，坚守面部隐私零外发底线。

### 2. 双轨渐进轻量抠图引擎 (Tolerance Matting & Dual-Track Eraser)
为规避数十兆大型离线深度学习模型对静态站点首屏的侵蚀，首期采用纯前端极速色彩分割与交互微调架构：
- **基准色采样与欧几里得色差容差 (Color Tolerance)**：自动探测四角背景色或通过吸管拾取基准色，计算像素间色彩距离并实施动态阈值剔除；
- **自适应边缘羽化 (Edge Feathering)**：消除硬边缘锯齿与发丝色斑；
- **擦除与恢复双修容画笔 (Erase & Restore Brushes)**：提供局部细节涂抹兜底，允许用户手动补全衣领发际或抹除背景残留；
- **免抠图通道**：天然支持直接上传已抠好的透明人像 PNG，直接一键填充底色。

### 3. 多维度标准规格库与合规参考线网格 (Spec Presets & Compliance Guidelines)
- 内置三大常用业务分类（通用尺寸、资格考试、证件签证）及自定义毫米/像素/DPI 引擎；
- 视窗内嵌动态合规参考线网格（涵盖头顶安全距、眼睛水平对齐基线、下巴轮廓基准），支持在保留原始画质前提下的交互式平移、缩放与旋转。

### 4. 冲印排版渲染管道 (Print Sheet Layout Pipeline)
支持 5 寸 (89×127mm) 与 6 寸 (102×152mm) 国际标准冲印相纸，根据所选单张证件照规格与相纸横纵朝向，自动计算最大容纳阵列矩阵与对称外边距，并在各单元四周自动绘制精确的 0.5px 十字裁切虚线，一键输出 300 DPI 冲印成品。

### 5. 目标体积二分搜索压缩器 (KB Target Compressor)
针对官方平台严格的 KB 体积区间约束，设计纯客户端二分查找算法（Binary Search）：
- 在 `quality` 区间 [0.05, 0.98] 内进行最多 8 次极速迭代，逼近最贴合且不突破上限的目标大小；
- 具备微等比下采样（Downsampling）兜底防线，确保极端体积约束下亦能 100% 达标导出。

### 6. 工具分层与规范落位 (Taxonomy & 5-Layer Blueprint)
依据 [ADR-0006](0006-canonical-tool-taxonomy-and-category-consolidation.md)，该工具统一命名为 **证件照制作工坊 (ID Photo Maker)**，落位于 `media`（图形多媒体）分类；严格遵循五件套规范拆分为视图、服务算法、类型契约、单元测试与元数据注册。

## 后果与影响
- **正面影响**：
  - 100% 离线保障，人脸肖像资产安全可控；
  - 零外部重量级 WASM/模型依赖，打包体积近乎零增长，秒级冷启动；
  - 完整打通规格、抠图、对齐、冲印排版、KB 体积达标的全生命周期闭环。
- **代价与权衡**：
  - 容差抠图对极度杂乱生活背景的自动分割能力弱于大参数量神经网络，需引导用户优先拍摄纯色背景或使用修容画笔配合。
